# skybook
[![Build Status](https://travis-ci.org/muxueqz/skybook.svg?branch=master)](https://travis-ci.org/muxueqz/skybook)

Light weight bookmark manager(delicious alternative)

## Features
* Search: via browser custom search engine
* Stores bookmarks as json, supports git versioning and backup to Github
* Runs locally, no network dependency, no server shutdown worries
